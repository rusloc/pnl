Voice-over

The Import model does its shaping inside Power BI. Power Query merges first and last names and adds net and cost amounts. A DAX column sorts products into price bands. A DAX table builds the calendar. Direct Lake tables have no Power Query, so that logic moves upstream. One notebook cell now does all of it, once, in the lakehouse, and every model that reads these tables gets the same result. For bigger models, Semantic Link Labs can script this migration. Here every step was done by hand, so you can see it.
