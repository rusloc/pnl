# Selection: from a request to one style

## 1. Intake (answer from the request; ask only if a blocking fact is missing)
| Question | Why it decides the style |
|---|---|
| **Purpose**: inform, sell, delight, identify, navigate? | sells/delights → expressive; navigates/identifies → restrained |
| **Audience**: who, how expert, what age? | pros & enterprise → calm, precise; youth & consumer → playful, saturated |
| **Medium & targets**: standalone file, app UI, social, print? | app UI → strict platform subset (svg-app-graphics); print → physical units |
| **Brand assets**: logo, colors, fonts that exist? | existing brand **overrides** trends; derive from it |
| **Tone words**: 2–3 adjectives the user gave or implied | map with the table below |
| **Lifespan**: campaign (weeks) or identity/system (years)? | short → trend-forward allowed; long → timeless base, at most one trend accent |

## 2. Tone word → visual attributes
| Tone | Shape | Line | Color | Type | Composition | Texture |
|---|---|---|---|---|---|---|
| Trustworthy, calm | geometric, rounded corners | even, medium | cool, low chroma, tinted neutrals | humanist sans or modern serif | symmetric/grid, generous space | none |
| Premium, quiet luxury | refined, sparse | hairline–thin | off-white, near-black, one metallic or deep accent | high-contrast serif + quiet sans | centered or strict asymmetric, lots of space | paper, fine grain |
| Playful, friendly | soft blobs, circles, squircles | round caps, thick | saturated, warm, 3–5 hues | rounded or chunky sans | dynamic, overlapping, tilted elements | none or soft 3D |
| Bold, rebellious | blocky, hard angles | thick borders | clashing brights + black | condensed/extended display, mono | anti-grid, oversized type | halftone, grain |
| Technical, precise | grid-aligned, orthogonal | 1–2px uniform | mono + one signal color | grotesk + mono | modular grid, data-like | none |
| Natural, organic | irregular, leaf/stone forms | tapered (ribbons) | earthy, muted greens/clays | humanist serif or soft sans | asymmetric, flowing | paper, watercolor |
| Nostalgic, retro | era-specific (70s curves, 80s grids, Y2K chrome) | era-specific | era palette | era display face | era layout conventions | print grain, halftone |
| Futuristic | sharp or liquid, glass | thin, glowing | dark base + neon or iridescent | extended grotesk, mono | spacious, centered | glow (web), gradients |

## 3. Purpose → shortlist (then pick ONE)
- **Brand mark / emblem** → Swiss geometric, Quiet luxury, Art deco, Monoline (catalog). Timeless first.
- **Icon set / app graphics** → Neo-minimal line or Soft 3D (svg-app-graphics trends); never mix.
- **Poster / campaign / social** → Bold type-led, Dopamine, Neo-brutal, Editorial, Retro-futurism.
- **Illustration / scene** → art styles A1–A20 (catalog), chosen by tone.
- **Data-ish / technical explainer** → Swiss/International, Technical precise.
- **Calm product / wellness / finance** → Neo-minimal calm, Cloud Calm palette, serif-revival type.

## 4. Decision rules
- **One style + at most one modifier** ("Swiss + grain", "Neo-minimal + soft 3D accents"). Two full styles read as confused.
- **Brand > trend.** Trends adjust the execution (type, texture, palette temperature), never the brand's core colors or logo.
- **Lifespan rule:** identity, icons and systems take a timeless base. Campaigns may be fully trend-led.
- **Constraint check:** if the target is mobile/app, the chosen style must survive the strict subset
  (no filters, masks or blend modes). Glass, grain and watercolor then become web/raster-only modifiers.
- **Name it:** every decision ends as the five-line Style Brief (SKILL.md). The build skills consume that, not prose.
