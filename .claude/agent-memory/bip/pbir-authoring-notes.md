- `powerbi-report-author` (0.4.0) and `powerbi-desktop` CLIs are installed globally; `powerbi-report-author validate "<x>.pbip" --format text` runs JSON-schema + semantic PBIR rules offline-capable. Use it after every PBIR edit. `scaffold` gives pinned schema versions (report 3.3.0, page 2.1.0, pages 1.1.0). (source: observed 2026-10-21)
- Rules it enforces: custom theme JSON `name` must equal report.json `customTheme.name`; dropdown slicer with header needs height ≥ 76 px; a 12 pt textbox needs ≥ 35 px. (observed)
- `expr encode --kind string` does not escape apostrophes — keep canvas text apostrophe-free or double them by hand. (observed)
- Formatting property *values* are not schema-validated (free-form), only names/structure — e.g. slicer default selection `objects.general.filter.filter` and button `icon.image` need Desktop to confirm. (observed)
- No powerbi-modeling MCP here: TMDL is authored as files; Desktop validates on open. (observed)
- Git Bash heredocs in this harness can mangle `\\` — use the Edit tool for patches containing backslashes. (observed)
- [2026-10-21] Grouped visuals: Desktop writes child `position` **relative to the parent group** (pl_matrix at 0,22 inside grp_view_pl). pbip-editor's pbir-visuals.md says "absolute page coordinates" — wrong for Desktop output. The generator wrote Slice / Period pop-up children in absolute coords, so they render offset by the group anchor. (observed)
- [2026-10-21] Desktop PBIR visual.json bytes: UTF-8 no BOM, CRLF, 2-space indent, literal non-ASCII (✕), no trailing newline. Docs in `docs/` are LF. `grep -c $'\r$'` in Git Bash misreports CRLF — measure with Python. (observed)
- [2026-10-21] Validator does not flag group children outside the group box; baseline errors after the USER's save: 4 × PBIR_BOOKMARK_VISUAL_REF_MISSING ("ind_pl" in bm_view_*). (observed)
- [2026-10-21] Desktop render findings (scratch copy opened with `powerbi-desktop open`, `reload --pid`, `screenshot --pid`): actionButton / shape / cardVisual honour `show` only in a **selector-less** entry (`{"properties":{"show":...}}`); `show` under `{"id":"default"}` is ignored (buttons then lose text and fill and get a dark default outline). (observed)
- [2026-10-21] Small cardVisuals (≤ 22 px) render no text until `layout` paddingUniform 0 / cellPadding 0, `padding` paddingSelection 'Custom' + margins 0 and `cardCalloutArea` paddingUniform 0 are set. Use `paddingSelection`/margins in `padding`, not top/bottom/left/right (validator error). (observed)
- [2026-10-21] Button slicer (`advancedSlicerVisual`): selection lives in `objects.general[0].properties.filter` (validator accepts); `orientation` is classic-slicer only. Per-item fx with `{"data":[wildcard 1],"id":"default"}` works (accent bar per company, Label role measure works). My `{"id":"selected"}` entries on fillCustom/value/outline were **not** honoured: Desktop showed its default selected style (dark fill, white text). The `background` object is a content box inside the tile padding, not the tile fill — don't use it as fill. Correct selected-state serialization still unknown: get it from a Desktop-saved file. (observed)
- [2026-10-21] Disabled-with-tooltip button: visualLink type 'Drillthrough' without a destination + `disabledTooltip`; disabled state styling via selector id 'disabled' rendered as expected (grey text, Subtle fill). (observed)
- [2026-10-21] Matrix: rules-based CF (`Conditional` on the column's own measure, `And` with a cheap flag measure) works; data bars in `columnFormatting.dataBars` {positiveColor, negativeColor, axisColor, reverseDirection, hideText} render; `expansionStates[].root.children[{identityValues, isToggled}]` opens blocks; set `values.backColorPrimary/Secondary` white and theme `tableAccent` to a grey to stop banding and blue rules. (observed)
- [2026-10-21] DAX query DEFINE syntax: `MEASURE _measures[Name] =` (no quotes inside the brackets). SUMMARIZECOLUMNS on a field-parameter column needs all its composite-key columns (Breakdown, Breakdown Fields, Order). Desktop AS port: `%LOCALAPPDATA%\Microsoft\Power BI Desktop\AnalysisServicesWorkspaces\*\Data\msmdsrv.port.txt` (pick the one whose model has `_measures`). (observed)
- [2026-10-21] Desktop guard: `Get-Process PBIDesktop` also matches other files (the USER had "Coal trucks.pbix" open); `powerbi-desktop status` lists each instance's file path and hasUnsavedChanges. (observed)

- [2026-10-21] tableEx images: every image cell is drawn in one `grid.imageWidth` x `imageHeight` box, and a smaller SVG is **centred** in it. A narrow column then shows nothing (the Δ pill vanished). Fix: give every SVG in the table the box size and draw its content at the left. Column alignment does not move images. (observed)
- [2026-10-21] `powerbi-desktop reload` re-reads PBIR only, never TMDL (a model change needs a fresh open). For test runs: open a scratch copy without `cache.abf` in my own instance, wait for the tables, then send TMSL `{"refresh":{"type":"full",...}}` over ADOMD (~13 s for Trucks). Scripts in the session scratchpad: run-dax.ps1, run-tmsl.ps1. `Stop-Process` only on my own PID. (observed)
- [2026-10-21] Fonts in visual *expressions* (cardVisual value, slicer, table, button): a bare `'Segoe UI Bold'` renders as a browser serif, because it is a weight and not a family. `'Segoe UI Semibold'` happens to work. Always write the stack, e.g. `'''Segoe UI Bold'', wf_segoe-ui_bold, helvetica, arial, sans-serif'`. Textbox runs take plain names. (observed)
- [2026-10-21] A 1x screenshot turns Segoe UI Semibold commas at about 20 pt into dots ("1.420.103"); at 2x they are commas. Check separators at `--scale 2` before blaming the culture. Hide the filters pane with report.json `outspacePane.visible false`: this applies to reading view and the service, and Desktop edit view still shows the strip. A tableEx with `isDefaultSort` shows no sort arrow. (observed)
- [2026-10-21] Native dropdown slicer with header (76 px), cardVisual text pattern with `labelDisplayUnits 1D`, container background/border fx with `Conditional` cases, and the `rectangleRoundedByPixel` shape all rendered as intended in Desktop on the first try (Trucks build). (observed)

- [2026-10-22] Render traces: `powerbi-desktop reload` of an unchanged PBIR re-renders from the visual cache (no queries); for timings open a fresh Desktop and attach a QueryEnd trace as soon as the port file appears (scratch `k24/trace_open.ps1`). Screenshots right after reload often show spinners: wait 30-60 s, take two. (observed)
- [2026-10-22] cardVisual small multiples (Rows role): grid of 4 needs smallMultiplesLayout orientation '0' + autoGrid true; rowCount/columnCount alone are ignored; without smallMultiplesOverFlow {overFlowStyle '1'} the cell reserves ~20 px top/bottom. A 179 px card shows only ONE reference-label row 'below' but ~4-5 lines 'right' (sentence style wraps title / value); valueArea, calloutSize, value/title font sizes, header topMargin had no visible effect. (observed)
- [2026-10-22] Image visual with `image.sourceType 'imageUrl'` + `sourceUrl` = measure (dataCategory ImageUrl) renders SVG data URIs; encode % as %25 and # as %23. Use it as a transparent overlay with its own query (progressive loading). (observed)
- [2026-10-22] Card value text: UNICHAR(10) line breaks render, but long text is clamped (~20 lines, '...') and placed low/centred. Button text bound to a measure: top-aligned, wraps, never clamps, but ignores line breaks (also U+2028/2029/0085). Text boxes (paragraphs, Semibold runs) are the reliable multi-paragraph text; line height ~18 px at 9 pt vs ~16 px in buttons/cards. (observed)
- [2026-10-22] Matrix expansion from hand-written PBIR: Desktop's collapsed form (levels isCollapsed true, root {}, level-1 projection active false) renders; root.children isToggled lists, level isCollapsed false and both projections active all left the matrix spinning or showed -/+ without leaves on a fresh open. Expanded states must be recorded in Desktop (bookmark Update). rowSubtotals true hung the visual. (observed)
- [2026-10-22] cardVisual `image` with imageUrl = measure (fx) is evaluated at the VISUAL TOTAL, never per small-multiple cell: selectors {id default}, {data wildcard 0/1 [+metadata] [+id]}, {metadata} all tested in fresh opens (only {id default} renders, total-level). Literal data-URI SVG/PNG render fine (position Bottom, fixedSize, size 64). Per-tile images = one card per tile (filter to the tile) -> total = tile. (observed)
- [2026-10-22] A one-cell small-multiples card insets its cell by layout padding but keeps the full width: the right border is clipped. Fix: layout paddingUniform 0, smallMultiplesBorder gridlineShow false, outline via VCO border {show, color, radius 12D, width 1D}. (observed)
- [2026-10-22] `powerbi-desktop reload` does re-apply formatting and visibility edits (verified); TMDL changes still need a fresh open. Calculated tables/columns added in TMDL are computed on open (no refresh needed in Desktop). Run the scratch DAX/trace scripts with powershell.exe (5.1), not pwsh. waitshot helper: scratch b8/waitshot.py (old shot_until.sh did not write files). (observed)
- [2026-10-22] waterfallChart: no per-bar colour (sentimentColors only: increase / decrease / total / other); the first category is always an increase from 0. Breakdown mode (Category = 2 stages, Breakdown = steps) orders breakdown items by size, not by sort column, and adds zero items -> unusable for an ordered bridge. Labels: labelDisplayUnits 1D = None (auto picked K for Group). (observed)
