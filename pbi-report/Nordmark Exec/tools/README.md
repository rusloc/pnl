# Nordmark Exec — generator and test tools

The `_measures` table (388 measures), the DAX tests (`../tests/control-totals.dax`) and the measure dictionary
(`docs/model/nordmark-measure-dictionary.md`) are generated by these scripts (bip; kept in the repo since 2026-10-30, CAND-028).
The PBIR report is **not** generated any more: since the period model it is the source itself and is patched surgically
(`gen/report_state.py` and the one-off `gen/report_category.py` are the report patches kept). Every path defaults to this repo layout; nothing machine-specific is
stored here.

## Requirements

- Python 3.12 with `Pillow` (Segoe UI text metrics for the pre-wrapped SVG copy; fonts from `%WINDIR%\Fonts`).
- Power BI Desktop (for the test and timing runners, which load its ADOMD / TOM client DLLs from `%ProgramFiles%\Microsoft Power BI Desktop\bin`).
- Node 22+ only to refresh the shared copy from `js-exec/lib/engine/copy.ts` (`NORDMARK_COPY_REFRESH=1`); otherwise the snapshot
  `gen/copy_ts.json` is used.

## Layout

| Path | What |
|---|---|
| `gen/measures.py` | Base layer (window = the `dim_week` rows in context, region via scoped leaf sums), status, card layer, texts |
| `gen/engine_k.py`, `gen/dim_item.py` | Period model (ADR-0013 (k)): picker measures, `dim_item` calculated table |
| `gen/measures_svg.py`, `gen/frame.py`, `gen/tokens.py`, `gen/fmt.py` | SVG faces and pop-ups; `frame.py` = one frame per SVG measure (perf pass 2026-10-30); `tokens.py` = worked examples / stats; `fmt.py` = DAX twins of `js-exec` `format.ts` |
| `gen/copy_v5.py`, `gen/copy_ts.json`, `gen/dim_kpi_cards.json` | Shared copy (snapshot of `js-exec/lib/engine/copy.ts`) and card attributes |
| `gen/common.py` | Paths, tokens, text metrics, writers (UTF-8 without BOM, CRLF for PBIP files) |
| `gen/build_model.py` | Whole model TMDL into `NORDMARK_ROOT` (use a scratch folder; the repo model is updated through `splice.py`) |
| `gen/splice.py` | Puts generated measures into the Desktop-saved `_measures.tmdl`: repo order and lineageTags kept |
| `gen/build_tests.py`, `gen/build_docs.py` | Tests and dictionary |
| `gen/export_sync.py` | Measure catalogue as JSON for `run/tom_sync.ps1` |
| `gen/report_state.py` | `tt_info` size from the pop-up height; saved slicer state = documented default (Week / FY2026 / W43 / Budget / All, no attribute picks) |
| `gen/report_category.py` | Category round (ADR-0013 (l)): the `menu_param_category` dropdown slicer, the Filters menu re-stacked, panel SVG labels, the 4 layer bookmarks; idempotent |
| `run/run-dax.ps1`, `run/run-tests.ps1`, `run/split_blocks.py` | Read-only DAX runner; block-by-block test runner |
| `run/time.ps1` | Cold timings: XMLA ClearCache before every query, one query per visual measure, 4 picker states |
| `run/export_faces.py` | Card faces, ⓘ texts, header line and dot / counts of 7 picker states as a CSV for the cross-flavour parity check |
| `run/tom_sync.ps1` | Pushes the generated measures into a **scratch** Desktop instance (in memory, nothing saved) |

Environment overrides: `NORDMARK_REPO`, `NORDMARK_ROOT` (output PBIP root), `NORDMARK_DATA` (Parquet folder), `NORDMARK_CHECKS`
(control totals CSV), `NORDMARK_CAT_CHECKS` (category control totals CSV), `NORDMARK_DOC` (dictionary), `NORDMARK_JS_EXEC`, `NORDMARK_FONTS`.

## Regenerate after a model change (PowerShell, from `pbi-report\Nordmark Exec\tools\gen`)

Close Power BI Desktop on the repo PBIP first (Desktop overwrites the files on save). `$scratch` is any empty folder outside the repo.

```powershell
$scratch = Join-Path $env:TEMP "nordmark-gen"
$env:NORDMARK_ROOT = $scratch; python build_model.py; python build_tests.py; Remove-Item Env:NORDMARK_ROOT
python splice.py "..\..\Nordmark Exec.SemanticModel\definition\tables\_measures.tmdl" "$scratch\Nordmark Exec.SemanticModel\definition\tables\_measures.tmdl" "$scratch\_measures.spliced.tmdl"
Copy-Item "$scratch\_measures.spliced.tmdl" "..\..\Nordmark Exec.SemanticModel\definition\tables\_measures.tmdl"
Copy-Item "$scratch\tests\control-totals.dax" "..\..\tests\control-totals.dax"
python build_docs.py
python report_state.py
powerbi-report-author validate "..\..\Nordmark Exec.pbip"
```

`build_model.py` also writes every table file; only `_measures.tmdl` is taken over (through `splice.py`) unless a table changed on
purpose. Back up the touched files to `../../__backup__/` first (Rule #1).

## Test and time (scratch Desktop instance)

Open a **copy** of the PBIP in Desktop, find its port (`%LOCALAPPDATA%\Microsoft\Power BI Desktop\AnalysisServicesWorkspaces\*\Data\msmdsrv.port.txt`), then:

```powershell
..\run\run-tests.ps1 -Port 12345 -Pattern "T-N[2-9]|T-N1-(ALL-P26|NL-P25|BE-P26|ONLINE-P25)"   # behaviour blocks + slowest T-N1 per scope
..\run\run-tests.ps1 -Port 12345                                                             # full run (about 2 h)
..\run\time.ps1 -Port 12345 -OutCsv "$env:TEMP\t.csv" -Repeat 3                               # cold timings, 4 states x 26 visual measures
```

Time on a freshly opened instance: after a `tom_sync.ps1` push the same instance reports higher cold times for every query
(the constant-query floor went from about 0.33 s to 0.74 s in the 2026-10-30 runs).
