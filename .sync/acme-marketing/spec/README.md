# Paid Acquisition Console

Spec and interactive mockup for a one-page, five-view dashboard that reports paid online ad campaigns for a SaaS product on web and mobile.

- **Open the mockup:** double-click `mockup/index.html`. No build, no server. Press `F` or the Filters button for the filter window; tabs switch views (`#overview`, `#channels`, `#campaigns`, `#journey`, `#cohorts`).
- **Read the spec:** `SPEC.md` — metrics, reading flow, layout, filter design, matte-glass visual system, data model.
- **For an AI assistant:** start at `AI_CONTEXT.md`, which maps every fact to its one location and lists task recipes.

All numbers in the mockup are illustrative.
