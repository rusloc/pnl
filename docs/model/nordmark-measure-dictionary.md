## How the measures work

- **Window = dim_week rows in context.** Every base measure (folders 1-7) evaluates over the weeks in its filter context and the
  region picked in `param_region` (the leaf sums apply `dim_store[scope_code]`; ALL = no filter). The card layer (8) sets the window:
  `[_Window Start]` .. `[_AsOf Index]` on `dim_week[sort_index]` from the period switcher (Week / Period to date / Year to date) and the
  as-of week of `manifest.json` (FY2026-W43 = 95). LY = `TREATAS` of the window's `ly_week_key`s; Last week = the same window type
  as of the week before (`[_LW Window Start]` .. as-of − 1).
- **Flow vs point in time (E-13).** Flow metrics sum over the window; stock, availability, GMROI, sell-through and channel mix take
  the window's last week. The EBITDA card always shows period to date (`[EBITDA PTD]`, E-40).
- **Status (E-22 .. E-26).** Badness per card in the rule unit, rounded to 10 decimals: On track if ≤ `watch_from`, Watch if ≤ `off_from`,
  else Off track (`param_status_rule`); the Watch edge is Watch (data README open point 9). Status is always vs budget / target
  (E-24); the dot uses the literal v5 rule over the cards with a status, N/A excluded, and follows period and region.
- **Pickers.** `param_period`, `param_comparator`, `param_region` (single select, force selection) and `param_attr_group / lever /
  horizon / owner / statement` (multi select) are disconnected tables. Attribute picks only conceal cards (`[Card Revealed <KPI>]`).
- **Texts** follow `js-exec/lib/engine/format.ts` (minus U+2212, `€2,318m` from €1 bn up, `pp`, trimmed targets `97%`) and the
  sentences of `view.ts`; copy comes from `js-exec/lib/engine/copy.ts` (shared copy source).

Card Mix Dev Channel =
VAR _s          = [_Window Start]
VAR _e          = [_AsOf Index]
VAR _ly         =
    CALCULATETABLE (
        VALUES ( dim_week[ly_week_key] )
        ,REMOVEFILTERS ( dim_week )
        ,dim_week[sort_index] >= _s
        ,dim_week[sort_index] <= _e
    )
VAR _s2         = [_LW Window Start]
VAR _e2         = [_AsOf Index] - 1
VAR _cmp        = [_Comparator Code]
VAR _v1         = CALCULATE ( [Mix Store %], REMOVEFILTERS ( dim_week ), dim_week[sort_index] >= _s, dim_week[sort_index] <= _e )
VAR _v2         = CALCULATE ( [Mix Online %], REMOVEFILTERS ( dim_week ), dim_week[sort_index] >= _s, dim_week[sort_index] <= _e )
VAR _v3         = CALCULATE ( [Mix Wholesale %], REMOVEFILTERS ( dim_week ), dim_week[sort_index] >= _s, dim_week[sort_index] <= _e )
VAR _c1         = SWITCH ( _cmp, "LY", CALCULATE ( [Mix Store %], REMOVEFILTERS ( dim_week ), TREATAS ( _ly, dim_week[week_key] ) ), "LW", CALCULATE ( [Mix Store %], REMOVEFILTERS ( dim_week ), dim_week[sort_index] >= _s2, dim_week[sort_index] <= _e2 ), CALCULATE ( [Mix Store % Bud], REMOVEFILTERS ( dim_week ), dim_week[sort_index] >= _s, dim_week[sort_index] <= _e ) )
VAR _c2         = SWITCH ( _cmp, "LY", CALCULATE ( [Mix Online %], REMOVEFILTERS ( dim_week ), TREATAS ( _ly, dim_week[week_key] ) ), "LW", CALCULATE ( [Mix Online %], REMOVEFILTERS ( dim_week ), dim_week[sort_index] >= _s2, dim_week[sort_index] <= _e2 ), CALCULATE ( [Mix Online % Bud], REMOVEFILTERS ( dim_week ), dim_week[sort_index] >= _s, dim_week[sort_index] <= _e ) )
VAR _c3         = SWITCH ( _cmp, "LY", CALCULATE ( [Mix Wholesale %], REMOVEFILTERS ( dim_week ), TREATAS ( _ly, dim_week[week_key] ) ), "LW", CALCULATE ( [Mix Wholesale %], REMOVEFILTERS ( dim_week ), dim_week[sort_index] >= _s2, dim_week[sort_index] <= _e2 ), CALCULATE ( [Mix Wholesale % Bud], REMOVEFILTERS ( dim_week ), dim_week[sort_index] >= _s, dim_week[sort_index] <= _e ) )
VAR _d1         = _v1 - _c1
VAR _d2         = _v2 - _c2
VAR _d3         = _v3 - _c3
VAR _j          =
    SWITCH (
        TRUE ()
        ,ABS ( _d1 ) >= ABS ( _d2 ) && ABS ( _d1 ) >= ABS ( _d3 )
            ,1
        ,ABS ( _d2 ) >= ABS ( _d3 )
            ,2
        ,3
    )
RETURN
    IF ( NOT ISBLANK ( _c1 ) && NOT ISBLANK ( _v1 ), _j * 1000 + SWITCH ( _j, 1, _d1, 2, _d2, _d3 ) )
