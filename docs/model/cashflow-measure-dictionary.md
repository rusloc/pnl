# ACME Cash Flow — measure dictionary

Generated by `pbi-report/ACME Cash Flow/tools/gen/build_docs.py` on 2026-11-26 from the same catalogue that writes `_measures.tmdl` (owner: bip). Governing record: ADR-0019 (amendment 1); numbers follow the accepted mock (`docs/design/cash flow statement/mockup-v2-core.js`) and the data contract `data/acme_cash_flow_dummy_data/README.md`.

- **Window.** Every measure reads the month indexes `_A` .. `_B` (0 = 2024-01) of the picked period (calendar pop-up: Year / Quarter / Month + YTD / QTD / MTD at Oct 2026). `dim_shift` PRIOR moves the window to the prior period (KPI deltas, mock `period().prior`).
- **Signs.** Cash in +, cash out −. Statement = indirect view with the S01 override on (line of credit in financing). Display units (USD / USD k) are applied in DAX (`_Div`, dynamic format strings that read only `_Is K`).
- **Tests.** `pbi-report/ACME Cash Flow/tests/control-totals.dax` (spec IDs in brackets below are tested there).

143 measures; 70 visible.

## 1 Statement

| Measure | Definition | Spec | Format |
| --- | --- | --- | --- |
| `Opening Cash` | Cash at the start of the window: Bank + Undeposited Funds opening balance of the first month (QBO cash set). | M01 | #,0.00 |
| `Closing Cash` | Cash at the end of the window: cash-set closing balance of the last month. | M02 | #,0.00 |
| `Net Change in Cash` | Closing less opening cash; equals operating + investing + financing. | M03 | #,0.00 |
| `Net Income` | Accrual net income of the window: minus the net change of every P&L account (ledger is debit positive). | M04 | #,0.00 |
| `Revenue` | Income-type accounts (credit as positive) over the window. | REVENUE | #,0.00 |
| `Account Adjustment` | Operating / investing / financing adjustment of the statement accounts in context: minus the change of the debit balance (asset up = cash out). | M05 | #,0.00 |
| `Operating Adjustments` | Total adjustments to reconcile net income: depreciation + working-capital accounts. | M06 − M04 | #,0.00 |
| `Investing Cash Flow` | Net cash from investing activities (indirect). | M07 | #,0.00 |
| `Financing Cash Flow` | Net cash from financing activities (indirect, line of credit moved here by S01). | M08 | #,0.00 |
| `Operating Cash Flow` | Net cash from operating activities: net income + adjustments (indirect, overrides on). | M06 | #,0.00 |
| `Stmt Value` | Statement row value in USD: section header = its total, Net income, one row per account (hidden when it did not move), Total adjustments, Net cash from the section. | – | #,0.00 |
| `Stmt Amount` | Statement amount in the picked units (cash out in parentheses, zero = –). | – | dynamic (units) |
| `Stmt % of NI` | Row as a share of net income (net income = 100 %), sign kept as parentheses, 1 dp under 10 %; n/m on every row when net income ≤ 0. | – | text |
| `Bal Value` | Pinned rows: cash at beginning, net increase (decrease), cash at end. | – | #,0.00 |
| `Bal Amount` | Pinned row amount in the picked units. | – | dynamic (units) |
| `Bal % of NI` | % of net income on the net-increase row only (opening and closing cash have none). | – | text |

### Stmt Value

```dax
Stmt Value =
VAR _a            = [_A]
VAR _leaf         = ISINSCOPE ( dim_stmt_row[row_label] )
VAR _sec          = SELECTEDVALUE ( dim_stmt_row[section_code] )
VAR _kind         = SELECTEDVALUE ( dim_stmt_row[row_kind] )
VAR _acc          = SELECTEDVALUE ( dim_stmt_row[account_id] )
VAR _sect         =
    SWITCH (
        _sec
        ,"OP", [Operating Cash Flow]
        ,"INV", [Investing Cash Flow]
        ,"FIN", [Financing Cash Flow]
    )
VAR _v            =
    SWITCH (
        TRUE ()
        ,ISBLANK ( _a )
            ,BLANK ()
        ,NOT _leaf
            ,_sect
        ,_kind = "NI"
            ,[Net Income]
        ,_kind = "ACC"
            ,CALCULATE ( [Account Adjustment], dim_account[account_id] = _acc )
        ,_kind = "TOT"
            ,[Operating Adjustments]
        ,_kind = "SECT"
            ,_sect
    )
VAR _hide         = _kind = "ACC" && _leaf && ABS ( _v ) < 0.005
RETURN
    IF ( NOT _hide, _v )
```

### Heat Cell Block

```dax
Heat Cell Block =
VAR _v            = [Heat Moved]
VAR _vc           = ROUND ( _v * 100, 0 )
VAR _a            = [_A]
VAR _b            = [_B]
VAR _sec          = SELECTEDVALUE ( dim_cf_line[section_code] )
VAR _grid         =
    CALCULATETABLE (
        ADDCOLUMNS (
            SUMMARIZE ( fact_cash_posting, fact_cash_posting[direct_line_code], fact_cash_posting[txn_date] )
            ,"@c", ROUND ( CALCULATE ( SUMX ( fact_cash_posting, ABS ( fact_cash_posting[amount] ) ) ) * 100, 0 )
        )
        ,REMOVEFILTERS ( dim_cf_line )
        ,dim_cf_line[section_code] = _sec
        ,REMOVEFILTERS ( dim_date )
        ,dim_date[month_index] >= _a
        ,dim_date[month_index] <= _b
        ,fact_cash_posting[is_internal_transfer] = FALSE ()
    )
VAR _nz           = FILTER ( _grid, [@c] > 0 )
VAR _n            = COUNTROWS ( _nz )
VAR _le           = COUNTROWS ( FILTER ( _nz, [@c] <= _vc ) )
RETURN
    SWITCH (
        TRUE ()
        ,ISBLANK ( _v )
            ,BLANK ()
        ,_vc <= 0
            ,0
        ,MIN ( 5, MAX ( 1, ROUNDUP ( _le * 5 / _n, 0 ) ) )
    )
```

```dax
        ,dim_stmt_row[sub_kind] = "WC"
    )
VAR _t            =
    CALCULATETABLE (
        ADDCOLUMNS ( VALUES ( dim_account[account_id] ), "@v", [Account Adjustment] )
        ,REMOVEFILTERS ( dim_account )
        ,TREATAS ( _ids, dim_account[account_id] )
    )
RETURN
    COUNTROWS ( FILTER ( _t, ABS ( [@v] ) >= 0.005 ) ) + 0
```

```dax
_Stmt Axis Max =
VAR _ids          =
    CALCULATETABLE (
        VALUES ( dim_stmt_row[account_id] )
        ,REMOVEFILTERS ( dim_stmt_row )
        ,dim_stmt_row[row_kind] = "ACC"
    )
VAR _acc          =
    MAXX (
        CALCULATETABLE (
            ADDCOLUMNS ( VALUES ( dim_account[account_id] ), "@v", ABS ( [Account Adjustment] ) )
            ,REMOVEFILTERS ( dim_account )
            ,TREATAS ( _ids, dim_account[account_id] )
        )
        ,[@v]
    )
VAR _m            =
    MAXX (
        {
            _acc
            ,ABS ( [Net Income] )
            ,ABS ( [Operating Adjustments] )
            ,ABS ( [Operating Cash Flow] )
            ,ABS ( [Investing Cash Flow] )
            ,ABS ( [Financing Cash Flow] )
            ,ABS ( [Net Change in Cash] )
        }
        ,[Value]
    )
VAR _e            = POWER ( 10, INT ( LOG10 ( MAX ( _m, 1 ) ) ) )
VAR _f            = MINX ( FILTER ( { 1, 1.25, 1.5, 2, 2.5, 3, 4, 5, 6, 8, 10 }, [Value] * _e >= _m ), [Value] )
RETURN
    IF ( _m > 0, _f * _e, 1 )
```
