# ACME Trucks — measure dictionary

> Model `pbi-report/ACME Trucks/Trucks.SemanticModel`, table `_measures`. Generated by bip on 2026-10-21 from the TMDL after the
> English rename and the orphan cleanup (76 measures: 60 kept from the live model "Time unitilaztion", 16 new for the
> "Time utilization" redesign; 2026-10-23: +2 for the waterfall tooltip page, 78 in total). ACME Trucks is outside the P&L spec, so there are no requirement IDs. Owner of every measure: bip.
> Tests: `pbi-report/ACME Trucks/tests/time-util.dax` (page) and `tests/baseline-live-en.dax` (parity with the live model).

Notes

- The KPI noise: `_KPI Noise = RANDBETWEEN ( 10, 100 )` multiplies the four tile measures `Rock Mass by Truck Plan/Fact` and
  `Performance per Truck Plan/Fact` (the live model had `RANDBETWEEN(10,100)` inline). The USER kept it for now. Removing it is one
  line: change the body of `_KPI Noise` to `1`; then update tab 6 of `tests/time-util.dax` and the KPI tabs of `baseline-live-en.dax`.
- While the noise is on, each card draws its own number, so the Δ pill on tiles 3–4 is not the difference of the two cards shown.
- The engine measures compare against data codes as DAX string literals (`"КФВ"`, `"Погрузка самосвалов"`, `"Неделя"`,
  `"Месяц"`, `"Линейно"`, `"Взвешенно"`, `"Проверка"`). These are data values and stay as they are (USER decision 1); the
  slicers show the English captions from the calculated columns `plan_type_name` / `calculation_name` / `category_name`.
- Values in the live model were unchanged by the rename: `tests/baseline-live-en.dax` passes 536/536 on the renamed model.

### `WF Plan Bar`

```dax
WF Plan Bar =
VAR _w            = 594
VAR _pad          = 8
VAR _track        = 533
VAR _h            = 24
VAR _is_subtotal  = [_WF Is Subtotal]
VAR _value        = COALESCE ( IF ( _is_subtotal = 1, [_WF Plan Subtotal], [_WF Plan Loss] ), 0 )
VAR _left         = IF ( _is_subtotal = 1, 0, COALESCE ( [_WF Plan Base], 0 ) )
VAR _x            = _pad + _left * _track
VAR _bar_w        = MAX ( _value * _track, 2 )
VAR _fill         = IF ( _is_subtotal = 1, "%231C2B3A", "%23A3AFC4" )
VAR _label        =
    IF (
        _is_subtotal = 1 && _bar_w > 48
        ,"<text x='" & FORMAT ( _x + 8, "0.0", "en-US" )
            & "' y='17' font-family='Segoe UI' font-size='15' font-weight='600' fill='%23FFFFFF'>"
            & FORMAT ( _value * 100, "0", "en-US" ) & "%25</text>"
    )
VAR _svg          =
    "data:image/svg+xml;utf8,<svg xmlns='http://www.w3.org/2000/svg' width='" & _w & "' height='" & _h
        & "' viewBox='0 0 " & _w & " " & _h & "'>"
        & "<rect x='" & FORMAT ( _pad + _track / 2 - 1, "0.0", "en-US" ) & "' y='0' width='1' height='" & _h & "' fill='%23E6EAF0'/>"
        & "<rect x='" & FORMAT ( _pad + _track - 1, "0.0", "en-US" ) & "' y='0' width='1' height='" & _h & "' fill='%23E6EAF0'/>"
        & "<rect x='" & FORMAT ( _x, "0.0", "en-US" ) & "' y='0' width='" & FORMAT ( _bar_w, "0.0", "en-US" )
        & "' height='" & _h & "' rx='4' fill='" & _fill & "'/>"
        & _label
        & "</svg>"
RETURN
    IF ( NOT ISBLANK ( _is_subtotal ), _svg )
```

```dax
_Fact Loss % Weighted =
// blank line

VAR _breakPoint = SELECTEDVALUE(dim_time_category[sort_order])
/*
    формируем виртуальную таблицу с колонками:
        1. собираем список всех ЭКС (SUMMARIZE)
        2. добавляем обьем ковша (@vol)
        3. добавляем признак АКТИВЕН (@active): смотрим была ли хоть одна запись с признаком Активен в таблице ПФ_КРВ
        4. считаем часы по категории простоя (@HOURS), отдельно по ключевым шагам КТГ, КИО, ПОГРУЗКА
        5. считаем общее время (@totalHours)
        6. в переменной _percent рассчитываем проценты (@hours / @totalHours) и фильтруем таблицу только по активным экскаваторам
        7. при выводе результата RETURN рассчитываем средневзвешенные (по ковшу) проценты по категориям простоя
*/
VAR _base = ADDCOLUMNS(
                SUMMARIZE(dim_loader,
                    dim_loader[loader_name_dispatch]),
            "@vol",
                CALCULATE(
                    MAXX(dim_loader,dim_loader[bucket_volume_m3])),
            "@active",
                CALCULATE(
                    MAXX(fact_time_actual,fact_time_actual[_active]),
                    ALL(dim_time_category)),
            "@hours",
                SWITCH(TRUE(),
                    _breakPoint = 6,
                        CALCULATE(
                            SUMX(
                                FILTER(fact_time_actual,
                                    fact_time_actual[_active] = 1),
                                fact_time_actual[duration]),
                            FILTER(ALL(dim_time_category),
                            dim_time_category[sort_order] IN {2,3,4,5})) / 3600,
                    _breakPoint = 24,
                        CALCULATE(
                            SUMX(
                                FILTER(fact_time_actual,
                                    fact_time_actual[_active] = 1),
                                fact_time_actual[duration]),
                            FILTER(ALL(dim_time_category),
                            dim_time_category[sort_order] IN {2,3,4,5,7,8,9,10,11,12,14,15,21,22})) / 3600,
                    _breakPoint = 27,
                        CALCULATE(
                            SUMX(
                                FILTER(fact_time_actual,
                                    fact_time_actual[_active] = 1),
                                fact_time_actual[duration]),
                            FILTER(ALL(dim_time_category),
                            dim_time_category[sort_order] IN {2,3,4,5,7,8,9,10,11,12,14,15,21,22,25})) / 3600,
                    CALCULATE(
                        SUMX(
                            FILTER(fact_time_actual,
                                fact_time_actual[_active] = 1),
                            fact_time_actual[duration])) / 3600),
            "@totalHours",
                    CALCULATE(
                        SUM(fact_time_actual[duration]),
                            FILTER(ALL(dim_time_category),
                        dim_time_category[category_code] = "КФВ")) / 3600)
VAR _percent = ADDCOLUMNS(
					FILTER(_base,
                        [@active] = 1),
                    "@percent",
                    SWITCH(TRUE(),
                        _breakPoint in {6,24,27},
                            1 - ([@hours] / [@totalHours]),
                        [@hours] / [@totalHours]))

RETURN

SWITCH(TRUE(),
    _breakPoint IN {6,24,27},
        0,
    DIVIDE(
        SUMX(_percent, [@percent] * [@vol]),
        SUMX(_percent, [@vol])))
```
