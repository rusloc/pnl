## How the measures work

- **Window.** The pickers are disconnected tables: `param_anchor_month` (closed month), `param_period` (Month / QTD / YTD / R12M),
  `param_comparator` (Budget / PY), `param_market` (All / PL / RO / PT). `_Win Start` / `_Win End` turn them into a `dim_month[month_index]`
  range (1 = Jan 2024). Every visible window measure is `CALCULATE ( [_Base], REMOVEFILTERS ( dim_month ), month_index in the window,
  KEEPFILTERS ( market ) )`; the PY twin shifts the range by 12 months. Period-end measures (portfolio, MRR, subscribers) use the anchor
  month only (`end_only`), which is the last closed month of every window.
- **Base measures** (`0 Base`, hidden) respect every filter; charts by month (`7 Trend`) evaluate them per `dim_month` row for the 13 months
  ending at the anchor.
- **EUR.** Actuals use the EUR columns of the data (`principal_eur`, `amount_eur`) or the `*_eur` columns derived on load in Power Query
  (`fact_loan_month`: local / ACTUAL_AVG rate of month x currency). Budget amounts use `fact_target[target_eur]` (local / BUDGET rate,
  derived on load). Constant currency (bridge FX step) uses `fact_loan[principal_eur_bud]`.
- **Tiers.** Tier 1 = the four Overview metrics and their comparators; Tier 2 = KPI band of views 2-5; Tier 3 = chart and table support;
  Design = text, titles and colours; Engine / Base = hidden plumbing.
- **Status** (design-tokens §6): counts / amounts good >= 0 %, watch -5 % to 0 %, off < -5 %; ratios good >= 0 pp, watch -2 to 0 pp;
  risk ratios good <= 0 pp, watch 0 to +0.5 pp; hours good <= 0, watch 0 to +0.5 h; attainment from `param_thresholds` (>= 100 % good,
  95-100 % watch). Rounded to the displayed precision before the band test. `n/a` when no comparator exists.
- **No budget in the data** for: approval, take-up, time to cash, returning %, repeat share, 90+ DPD, 30+ by count, vintage, roll rate,
  cost of risk, interest alone, fees alone, MRR, subscribers, channels. Those cards show `vs Budget n/a` when Budget is selected.

        CROSSJOIN (
            VALUES ( dim_month[month_key] )
            ,VALUES ( dim_market[market_code] )
            ,VALUES ( dim_product[product_code] )

        _step
